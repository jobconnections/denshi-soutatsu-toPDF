# e-Gov 電子送達 ZIP to PDF 変換ツール (denshi-soutatsu-pdf)

e-Gov（電子政府の総合窓口）からダウンロードされた電子送達の公文書ZIPファイル（XMLおよびXSLスタイルシート）を読み込み、帳票の種類に応じた最適なレイアウトで整形された高品質な **A4 PDFファイル** に自動変換するツールです。

---

## 📌 主な特長

- **ドラッグ＆ドロップで簡単変換**: ZIPファイルやフォルダをEXEアイコンにドロップするだけで即座に変換されます。
- **帳票別の自動レイアウト最適化**:
  - **増減内訳書**: 横向き（Landscape）、2ページ構成に最適化。
  - **社会保険料額情報**: 横向き（Landscape）、1ページ完結の高精度レイアウト。
  - **保険料納入告知額・領収済額通知書**: 縦向き（Portrait）、A4用紙に最適化したフォントと拡大率設定。
- **外部ランタイム不要（単一EXE）**: Node.js のインストールは不要です。単体の `.exe` ファイルのみで動作します。
- **完全ローカル・オフライン動作で高セキュリティ**: インターネット通信を一切行わず、すべての変換処理が PC（ローカル環境）内で完結します。電子送達のデータが外部サーバーへ送信される心配はありません。
- **標準ブラウザ活用**: Windows 標準搭載の Microsoft Edge（または Google Chrome）の描画エンジンを利用するため、別途巨大な Chromium をダウンロードする必要がありません。
- **バッチ処理・自動化対応**: 複数ファイルの一括処理や、スクリプトからの自動呼び出しに対応しています。

## 🚀 使い方

用途に合わせて、以下のいずれかの方法でご利用いただけます。

### 方法 1: ドラッグ＆ドロップで変換（一番簡単）
1. 変換したい e-Gov の `ZIPファイル`（またはZIPファイルが入ったフォルダ）を選択します。
2. **`denshi-soutatsu-pdf.exe`** のアイコン上に直接ドラッグ＆ドロップします。
3. 自動的に変換が実行され、対象フォルダ内に `output` フォルダが作成されてPDFが出力されます。

> **💡 ヒント（リポジトリ／ソースコードからご利用の場合）:**  
> ソースコード一式をクローンして利用している場合は、同一フォルダに `denshi-soutatsu-pdf.exe` または Node.js 環境があれば、付属の `convert.bat` へのドラッグ＆ドロップでも同様に実行できます。(`convert.bat` 単体では動作せず、同一階層に `denshi-soutatsu-pdf.exe` もしくは Node.js 実行環境と `index.js` が必要です)

### 方法 2: 同じフォルダに置いてダブルクリック
1. `denshi-soutatsu-pdf.exe` を変換対象の ZIP ファイルと同じフォルダに配置します。
2. `denshi-soutatsu-pdf.exe` をダブルクリックして起動します。
3. フォルダ内のすべての ZIP ファイルが自動検出され、一括で PDF に変換されます。

### 方法 3: コマンドライン（CLI）・バッチファイルからの利用
コマンドプロンプトや PowerShell、バッチスクリプトから引数を指定して実行できます。

```bat
:: 単一ファイルの変換
denshi-soutatsu-pdf.exe "C:\Path\To\1381260813758444_20260821163251.zip"

:: フォルダ内の全ZIPを一括変換
denshi-soutatsu-pdf.exe "C:\Path\To\ZipFolder"

:: 自動処理用（終了時の「Enterキーを押してください」をスキップ）
denshi-soutatsu-pdf.exe "C:\Path\To\ZipFolder" --no-pause
```

#### コマンドライン引数オプション
- `<ファイルパス/フォルダパス>`: 処理対象の ZIP ファイルまたはフォルダ（複数指定可能）。
- `--no-pause` または `-y`: 処理完了後のキー入力待ち（一時停止）を無効化します（バッチ自動連携向け）。

## 📄 対応帳票とレイアウト仕様

本ツールは、ZIP 内の XML ファイル名や構成を自動判別し、帳票に最適なスタイルを自動適用します。

| 帳票名 | 用紙向き | ページ構成・デザイン仕様 |
| :--- | :--- | :--- |
| **増減内訳書** | 横向き (Landscape) | 2ページ構成、余白・テーブル余白の自動調整 |
| **社会保険料額情報** | 横向き (Landscape) | 1ページ完結、枠線・テーブル幅の精密配置（Yu Mincho） |
| **保険料納入告知額・領収済額通知書** | 縦向き (Portrait) | A4縦1ページ、フォント（Yu Mincho）・改行・縮尺の最適化 |
| **その他の電子公文書** | 自動判定 | 標準XML/XSLTレンダリングによるPDF化 |

---

## 📂 出力先

- 変換された PDF ファイルは、対象 ZIP ファイルが存在するディレクトリ直下の **`output`** フォルダ内に保存されます。
  - 例: `C:\data\sample.zip` を処理した場合 → `C:\data\output\帳票名_日付(ID).pdf`

## 🛠️ 開発者向けガイド

ソースコードから実行・カスタマイズ、または EXE を再ビルドする場合の手順です。

### 1. 必要環境
- Node.js 20.x 以上推奨
- npm

### 2. 依存関係のインストール
```bash
npm install
```

### 3. ソースコードからの直接実行
```bash
# 通常起動（カレントディレクトリのZIPを変換）
npm start

# 引数を渡して実行
node index.js "path/to/target.zip"
```

### 4. 単一 EXE ファイルのビルド
Node.js の **SEA (Single Executable Application)** と **esbuild** を使用して、依存関係をすべて内包した単一バイナリを生成します。

```bash
# npm コマンドでビルド
npm run build

# または付属のバッチファイルを実行
build.bat
```
ビルドが完了すると、ルートディレクトリに `denshi-soutatsu-pdf.exe` が生成されます。
